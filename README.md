# Optom.uz price types prototypes

Clickable HTML prototypes P-PT1 – P-PT4 for the user stories of epic US-SF-2.2 (Price types and negotiable price), published with GitHub Pages and embedded in the Confluence user story pages.

Requirements: Price types and negotiable price PRD. Source of truth: the Confluence story pages. Example data only, no real customer data.

P-PT3 and P-PT4 are built from `src/` with `build.py`; P-PT1 and P-PT2 are single-file prototypes in `src/`, copied with small corrections by `build.py`.
